# Para minha nega ❤️

Uma página especial feita como surpresa romântica, com fotos e uma mensagem dedicada.

## Sobre o projeto

O site foi desenvolvido em HTML e reúne:

- 10 fotos do casal em uma galeria;
- fotos que podem ser ampliadas;
- uma carta com uma declaração especial;
- animações suaves de corações;
- visual delicado em tons de rosa, com detalhes românticos;
- layout adaptado para celular e computador.

## Arquivos

- `index.html` — página completa do site. O HTML já contém os estilos, scripts e imagens necessários.

## Como visualizar

Baixe ou extraia os arquivos e abra `index.html` em um navegador (Chrome, Firefox, Edge ou outro).

## Como publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie o arquivo `index.html` e este `README.md` para a raiz do repositório.
3. No repositório, acesse **Settings** → **Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/(root)`.
6. Clique em **Save** e aguarde a publicação.
7. O GitHub exibirá o endereço público do site na seção **Pages**.

## Personalização

Para alterar textos ou fotos, edite o arquivo `index.html`. Como o projeto está em um único arquivo, não é necessário configurar bibliotecas ou instalar dependências.
